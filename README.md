# PROJEK GUI UMKM PBO PA AKMAL
KASIR AYAM GEBUG MA' NYA

# TUJUAN
Kami membuat proyek ini dengan tujuan untuk mempermudah pengelolaan pesanan di Warung Ayam Gepuk Ma'nya. Selama ini, kesalahan seperti pesanan tertukar, lupa menambahkan minuman, atau tidak tercatat dengan benar cukup sering terjadi.

Melalui sistem ini, kami ingin menyediakan langkah preventif agar kesalahan dalam mencatat maupun menyimpan order dapat diminimalkan. Selain itu, proyek ini juga dirancang untuk membantu tim dapur bekerja lebih teratur, mulai dari proses memasak hingga proses pengemasan—dengan urutan yang jelas dan mudah diikuti.

Dengan demikian, sistem ini diharapkan mampu meningkatkan ketepatan pesanan, mempercepat alur kerja, dan membuat pelayanan menjadi lebih efisien.
